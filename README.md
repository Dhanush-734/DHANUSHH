## 🚀 Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/Dhanush-734/DHANUSHH.git
cd DHANUSHH
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
npm run preview
```
